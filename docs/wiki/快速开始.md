# 快速开始

## 1. 安装

1. 从 [Releases](../../releases/latest) 下载 `frpc-desktop-multi-<版本>-android-arm64.apk`
2. 在手机上打开，允许「未知来源」安装
   - 小米/OPPO 等机型会提示「未经安全审核」，点「继续安装」即可
   - 若覆盖安装失败，先卸载旧版
3. App 需要通知权限（前台服务常驻通知），首次启动按提示授予

> 桌面端：Windows 下载 `frpc-desktop-multi-<版本>-windows-x64-setup.exe` 双击安装，或下 zip 便携版解压运行。

## 2. 准备 frps

App 是 **frpc 客户端**，需要你已有可用的 frps 服务端。最小服务端配置（`frps.toml`）：

```toml
bindPort = 7000
auth.method = "token"
auth.token = "your-token"

# 需要 HTTP/HTTPS 代理时再加：
# vhostHTTPPort = 80
# vhostHTTPSPort = 443
```

启动：`frps -c frps.toml`。

## 3. 第一个穿透（以 SSH 为例）

1. **配置** → 右下角「新建配置」
2. 填写：
   - 配置名称：`我的服务器`
   - 服务器地址：frps 的 IP 或域名
   - 服务器端口：`7000`
   - 认证 Token：与服务端一致
   - 保持「启用状态监控（本机接口）」开启
3. 保存 → 进入该配置 → **代理规则** 点 `+`
   - 名称：`ssh`
   - 类型：`TCP`
   - 本地地址：`127.0.0.1`，本地端口：`22`
   - 远程端口：`6001`（0 表示由 frps 随机分配）
4. 保存后回到**主页**，点「启动」

日志出现以下内容即成功：

```
login to server success, get run id [...]
proxy added: [ssh]
[ssh] start proxy success
```

之后在任意机器执行 `ssh -p 6001 用户@frps地址` 即可连到手机的 SSH（如果手机开了 sshd）。

## 4. 验证状态

- 主页「代理规则」应显示 **在线**，并给出实际远端端口
- 下拉通知栏可见运行摘要（服务器 / 在线代理数 / 运行时长 / CPU / 内存）
- 手机浏览器打开 `http://127.0.0.1:7400/static/` 可看到官方 Web 控制台
